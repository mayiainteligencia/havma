# Havas Data - Design Tokens

Este documento define el sistema de tokens visuales y la paleta de colores corporativos.

## Colores Base Havas
- **Rojo (Primario)**: `#B22222`
- **Rojo Oscuro**: `#8E1B1B`
- **Negro (Texto)**: `#0F172A`
- **Blanco (Fondo Clásico)**: `#FFFFFF`

## Tokens de Tema

| Token | Light Mode | Dark Mode | Descripción |
|-------|------------|-----------|-------------|
| `--color-primary` | `#B22222` | `#B22222` | Acento principal de Havas |
| `--color-primary-dark` | `#8E1B1B` | `#8E1B1B` | Hover de botón primario |
| `--color-success` | `#10B981` | `#10B981` | Éxito y confirmaciones |
| `--color-warning` | `#F59E0B` | `#F59E0B` | Advertencias y pendientes |
| `--color-danger` | `#EF4444` | `#EF4444` | Errores y caídas (no confundir con rojo Havas) |
| `--color-background` | `#F8FAFC` | `#0F172A` | Fondo general de la app |
| `--color-surface` | `#FFFFFF` | `#1E293B` | Fondo de paneles y widgets |
| `--color-surface-hover` | `#F1F5F9` | `#334155` | Fondos secundarios y hovers |
| `--color-text-main` | `#0F172A` | `#F8FAFC` | Texto principal (títulos) |
| `--color-text-muted` | `#64748B` | `#94A3B8` | Texto secundario y etiquetas |
| `--color-border` | `#E2E8F0` | `#334155` | Bordes de separación |

## Sombras y Bordes
- `--shadow-sm`: Sutil para widgets.
- `--shadow-md`: Elevación por defecto de paneles.
- `--shadow-lg`: Hover en paneles interactivas.
- `--radius-md`: 8px para botones y tags.
- `--radius-lg`: 16px para tarjetas y Kpis.
- `--radius-xl`: 24px para paneles principales.
